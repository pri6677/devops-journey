# Lecture 01: What We Will Learn in This Networking Series

## 1. Networking Fundamentals
- What happens when we make an HTTP request.
- IP addresses and how they work.
- CIDR notation.
- Subnets and subnet masks.
- Default gateways.
- MAC addresses.

## 2. Network Communication and Routing
- ARP (Address Resolution Protocol).
- OSI and TCP/IP models.
- How packets travel between different networks.
- How switches and routers handle network traffic.

## 3. Network Diagnostics
- ICMP.
- `ping` and `traceroute`.
- How to troubleshoot network connectivity.
- How to inspect real network traffic using Wireshark.

## 4. Transport Layer Protocols
- UDP and its datagram structure.
- TCP and how reliable communication works.
- TCP three-way handshake.
- TCP connection states.
- Sequence and acknowledgment numbers.
- Flow control and congestion control.

## 5. Application Layer Protocols
- DNS queries and DNS record types.
- HTTP/1.1, HTTP/2, and HTTP/3.
- WebSockets.
- TLS and secure communication.
- DHCP and automatic IP configuration.
- NAT (Network Address Translation).

## 6. Practical Networking Skills
Throughout the course, we'll use tools such as Wireshark to inspect real network traffic and understand how networking protocols work in practice.

We'll focus on understanding the concepts rather than simply memorizing definitions.

### Our Goal

By the end of this series, we'll have built a strong foundation in computer networking that supports our **Cloud and DevOps learning journey**.
